# Sample lecture materials

These synthetic files contain no student data. They exercise formatted lecture text and a flow diagram in both formats; the PowerPoint also includes an embedded chart.

- `virtual-memory-notes.docx` — formatted headings, paragraphs, numbered steps, and an embedded paging diagram.
- `virtual-memory-lecture.pptx` — lecture text, an embedded paging diagram, and a chart with sample page access values.

Use them to check extraction in the local app. They are only fixtures, not app content or a replacement for testing a real lecturer document.
